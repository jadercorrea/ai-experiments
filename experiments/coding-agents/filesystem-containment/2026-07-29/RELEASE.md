# Local coding agents and filesystem containment

The first AI Experiments publication contains the raw evidence for two
sequential Devstral Small 2 campaigns against a strengthened Go
filesystem-containment contract.

- Capability check: 1/1 passed in 26m08s.
- Repeatability campaign: 0/3 passed; all three runs reached the 30-minute
  timeout.

The archive retains baseline metadata, patches, command logs, event streams,
verification results, and initial and final snapshots. Generated workspaces
and their Git internals are intentionally omitted.

Read the
[experiment report](https://github.com/jadercorrea/ai-experiments/tree/2026.07.29.1/experiments/coding-agents/filesystem-containment/2026-07-29)
before interpreting the result. It documents the protocol, human-review
boundary, and historical harness-provenance limitation.
