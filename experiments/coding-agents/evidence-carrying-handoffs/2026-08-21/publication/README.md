# Publication boundary

This directory describes the **public protocol preview v0.1** snapshot dated
2026-08-24. It is not an experiment-results release and is not a frozen
preregistration.

Files:

- `preview-manifest.json` encodes the publication status and exclusions;
- `artifact-lock.json` protects the experiment tree with deterministic SHA-256
  file and tree digests;
- `AI_USE_DISCLOSURE.md` records how AI assisted protocol construction.

Confirmatory task identities, hidden evaluator contents, model locks,
assignment schedules, and study outcomes are intentionally absent. Formal
CalVer releases will be created only when a complete frozen or results package
meets the repository publication contract. This preview should be cited by
experiment ID, preview version, snapshot date, and Git commit.
